# notes-mcp 文档导航

> notes-mcp 是把 markdown 笔记目录转成 **MCP 知识助手** 的 AI Agent 项目——
> 用 `search → get → prompts` 三层原语,让任意 MCP client(Claude Desktop / Cursor / 自写 agent / Web UI)「懂你的笔记」,并产出讲解 / 复习 / 自测 / 对比等可用结果。

---

## 文档怎么放

文档**按软件开发阶段分文件夹存放**(编号 `00`~`05`,阶段顺序排列),配合**两类命名规则**:

- **living 类**(持续更新,文件名固定):开发规范、配置、踩坑记录、测试总览、项目实现解析——靠 git 追溯历史
- **快照类**(一次性产出,文件名带日期+版本):需求/设计/选型/迭代计划/单次测试/交接——保留新旧版

规范详见 `~/.claude/skills/dev-doc/SKILL.md`。

---

## 6 个阶段文件夹

| 文件夹 | 放什么 |
|---|---|
| **00-总览/** | 项目文档导航(本 README)、架构全景图 |
| **01-需求/** | Requirements:需求分析(项目/阶段起点的「做什么」) |
| **02-设计/** | Design:设计文档、前端设计资料;下分 `选型/`(技术选型报告)和 `迭代计划/`(每次大改的计划) |
| **03-实现/** | Implementation:开发规范、配置、项目实现解析(living);下分 `交接/`(每次 session 接力快照) |
| **04-测试/** | Testing:测试总览(living)+ 单次测试 / eval 报告(快照,带 semver+githash) |
| **05-记录/** | Records:踩坑记录等累积型(living,只保留最新) |
